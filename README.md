
# SemLearn 📚

A Java Swing-based learning application designed to help B.Tech CSE students access their semester subjects and learning resources in one place.

## 🚀 Project Overview

SemLearn is a desktop application developed using Java Swing. It aims to make semester learning more organized by providing student registration, login, a dashboard, and subject-wise learning resources.

## ✨ Features

- Student registration
- Student login
- Dashboard interface
- Semester subject listing
- File-based storage for registered student accounts
- Subject-wise learning resources (under development)

## 🛠️ Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- File Handling
- Git and GitHub

## ▶️ How to Run

### Prerequisites

- Java Development Kit (JDK) installed
- Visual Studio Code or another Java IDE

### Steps

1. Clone this repository:

   ```bash
   git clone https://github.com/ashwini-bobbili/semLearn.git
   ```

2. Open the project folder in your IDE.
3. Compile the Java files, ensuring package declarations and source paths are correct.
4. Run the `Main` class to launch the application.
